\section{Regression Modelling and Statistical Evaluation}
\label{sec:modelling}
%% ============================================================================
\subsection{Experimental design}
\label{subsec:modelling_design}
\subsubsection{Data sets and splits}
The data experiments utilise three different features sets: the AE, the US, and the combined AE and US feature sets. Each of the later described models are fitted to each of the three datasets. Each dataset is divided into a training set (80\%) and a hold-out test set (20\%) by a \emph{visit-grouped} split: sweeps are partitioned into groups corresponding to contiguous 60-second RPM holds (both sensor rows of a sweep kept together), and whole groups---rather than individual sweeps---are assigned to the training or hold-out set with \texttt{GroupShuffleSplit}. This prevents the near-duplicate windows of a single slowly-varying hold from straddling the train/test boundary, as a sweep-level random split would allow. The hold-out set is withheld entirely from all model development steps and used only for final evaluation. The training set is further divided during nested cross-validation described in Section~\ref{subsec:nested_cv}.

\subsection{Repeated nested cross-validation}
\label{subsec:nested_cv}
To obtain stable performance estimates that properly account for the variance introduced by the train/validation split, the model evaluation uses a repeated nested $k$-fold cross-validation scheme. The outer loop is repeated $R = \resNrepeats$ times with independently re-seeded, group-respecting \resNfoldsCv-fold splits (the same hold-group structure as the hold-out split, so near-duplicate windows never straddle a fold boundary), yielding $R \times k = \resNouterScores$~outer RMSE scores per model--sensor combination. See Figure~\ref{fig:data_partition} for data partitions.

\begin{figure}[H]
\centering
\includegraphics[width=1\textwidth]{figures/nested_cv_splits.png}
\caption{Data partitioning for the repeated nested cross-validation: an 80/20
group-level hold-out split (groups = 60-second RPM holds), with the training pool
further divided into $R = \resNrepeats$ independently seeded, group-respecting
\resNfoldsCv-fold outer splits and inner hyperparameter-selection folds.}
\label{fig:data_partition}
\end{figure}

For LightGBM, each outer fold contains its own inner Optuna optimisation loop, ensuring that the reported outer scores are not contaminated by hyperparameter selection on the outer fold data.
For the linear models, hyperparameter selection runs within each outer training partition: \texttt{ElasticNetCV} performs an inner 5-fold search over the $\alpha$/$\ell_1$-ratio grid, and \texttt{RidgeCV} a leave-one-out generalised cross-validation over the $\lambda$ grid; the selected hyperparameters are then refit on the full outer-training fold before the outer validation fold is scored. These inner resampling schemes are not group-aware, so near-duplicate sweeps from the same hold may render their hyperparameter scores mildly optimistic; this affects only the selected penalties, as final performance is scored on the visit-grouped outer folds.

The \resNouterScores~outer scores form the empirical sampling distribution of RMSE for each model and are used directly in the significance tests described below.
\subsection{Statistical significance testing}
\label{subsec:sig_tests}
Pairwise significance tests are conducted at two levels, with the batteries
summarised in Table~\ref{tab:test_protocol}. \emph{Within-sensor} comparisons
(architecture differences, e.g.\ Elastic Net vs.\ Polynomial on AE) ask which
model generalises better and are assessed on the \resNouterScores~repeated
nested-CV fold RMSEs. \emph{Cross-sensor} comparisons (the best model per sensor
configuration, selected by lowest mean CV RMSE) are the study's focal claims and
are assessed both on the CV fold RMSEs and on per-sample residuals from the
common hold-out set. The Nadeau--Bengio corrected $t$-test~\cite{nadeau_inference_2003}
gauges robustness across resampling partitions---correcting the paired $t$-test
for the positive correlation induced by training-set overlap across folds---while
the hold-out tests gauge the difference on held-out data and the bootstrap supplies
an effect size. All $p$-values are Holm--Bonferroni-corrected within each family
at $\alpha = 0.05$; where CV and hold-out evidence diverge, both are reported.

\textbf{Overall performance.}
LightGBM achieves the best hold-out performance across all sensor configurations,
with AE-only reaching $R^2 = \resHOrsqLgbAe$, RMSE~$= \resHOrmseLgbAe$~$\kappa$-units.
On a target range of $[\resKappaMin,\, \resKappaMax]$ with mean~\resKappaMean, this corresponds to a relative
RMSE of approximately \resRelRmsePctLgbAe\% of the mean target value.
Linear and polynomial models on AE features achieve $R^2 = \resHOrsqPolyAe$--$\resHOrsqEnetAe$,
confirming a non-linear feature--$\kappa$ mapping that gradient boosting exploits
more effectively. The within-sensor corrected repeated nested-CV $t$-test
(Table~\ref{tab:test_protocol}) confirms this gap is significant: LightGBM
outperforms both linear families on AE (vs.\ Elastic Net $p = \resPcvLgbEnetAe$,
vs.\ Polynomial $p = \resPcvLgbPolyAe$; Holm-corrected), whereas the two linear
families are statistically indistinguishable.

\textbf{Sensor comparison.}
AE features substantially outperform US features across all model families.
The LightGBM AE--US gap ($\Delta R^2 = \resDrsqLgbAeUs$) is large and unambiguous on the hold-out set, although the corrected repeated nested-CV $t$-test does not reach significance; we report both (Table~\ref{tab:inference}).
This reflects the richer frequency content and more direct physical sensitivity of
the AE sensor to asperity contact events.

\textbf{Sensor fusion.}
LightGBM on the combined AE+US feature set achieves $R^2 = \resHOrsqLgbComb$
($\Delta R^2 = \resDrsqLgbCombAe$ over the AE-only result of \resHOrsqLgbAe).
The gain is significant under both the corrected repeated nested-CV $t$-test and all hold-out tests (Table~\ref{tab:inference}).
For the linear models, the combined feature set performs better than AE alone
(Elastic Net: $R^2$ \resHOrsqEnetComb{} vs.\ \resHOrsqEnetAe; Polynomial:
\resHOrsqPolyComb{} vs.\ \resHOrsqPolyAe).
Although the absolute $R^2$ gain is modest, this is a relative RMSE reduction of about \resRelRmseRedCombAe\% over AE alone, consistent across all four tests, indicating that the US channel contributes genuine, statistically robust non-redundant information.

\textbf{Model consistency.}
The close agreement between nested CV RMSE and hold-out RMSE across all models
indicates stable generalisation with no evidence of significant overfitting.

Figure~\ref{fig:pred_vs_actual} shows predicted vs.\ actual $\kappa$ on the hold-out
set for all model families and sensor configurations, coloured by RPM.

\begin{figure}[H]
\centering
\includegraphics[width=\textwidth]{figures/model_pred_vs_actual_holdout.png}
\caption{Predicted vs.\ actual $\kappa$ on the hold-out test set for all model families and sensor configurations, colored according to RPM. The dashed diagonal indicates perfect prediction. Residual spread increases in the mixed lubrication regime ($0.5 \leq \kappa < 1.0$). }
\label{fig:pred_vs_actual}
\end{figure}

Across the grid, predictions track the diagonal most closely for LightGBM---tightest
in the AE and combined configurations---whereas the Elastic Net and polynomial
families systematically under-predict at high $\kappa$, their points bowing below the
diagonal. For every model the residual spread widens in the mixed-lubrication regime
($0.5 \leq \kappa < 1.0$) and toward the under-represented full-film range
($\kappa > 1$); the RPM colouring reflects the operating-point dependence of $\kappa$
(Section~\ref{subsec:confound}).

\textbf{SHAP-based feature importance.}
SHAP (SHapley Additive exPlanations) values computed via TreeExplainer identify
which features drive the $\kappa$ predictions for each sensor
(Figure~\ref{fig:shap}). For the AE LightGBM model the dominant contributor by a
large margin is \textit{\resShapTopFeat} (mean $|\text{SHAP}| = \resShapTopVal$),
followed by \textit{\resShapSecondFeat} (\resShapSecondVal) and
\textit{\resShapThirdFeat} (\resShapThirdVal); this 500~kHz--1~MHz mobility feature
ranks \emph{first} for both LightGBM and the polynomial model and third for Elastic
Net, the most robust single AE predictor across model families. The US model is led
instead by \textit{\resShapTopFeatUs} (\resShapTopValUs), then
\textit{\resShapSecondFeatUs} (\resShapSecondValUs) and \textit{\resShapThirdFeatUs}
(\resShapThirdValUs). The two channels thus rely on distinct features whose operating-condition leanings
differ---the dominant AE feature is speed-tracking, whereas the dominant US feature
is the temperature-leaning 10--20~kHz mobility (Figure~\ref{fig:marg_cond})---so SHAP
independently corroborates their separate-channel structure. (The US band labels
refer to the probe's heterodyned audio baseband, not raw acoustic frequencies, so the
contrast is one of operating-condition channel rather than frequency.)
