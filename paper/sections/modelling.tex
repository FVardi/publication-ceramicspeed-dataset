\section{Regression Modelling and Statistical Evaluation}
\label{sec:modelling}
%% ============================================================================

\subsection{Experimental design and holdout split}
\label{subsec:modelling_design}

The dataset is divided into a training set (80\%) and a hold-out test set (20\%) by
sweep-level random sampling, stratified to preserve the $\kappa$ regime distribution.
The hold-out set is withheld entirely from all model development steps and used only for
final evaluation.

Three regression model families are evaluated for three sensor configurations
(AE only, UL channel only, and combined AE+UL features):
\begin{enumerate}
  \item \textbf{Elastic Net} (regularised linear regression with combined $\ell_1$ and
    $\ell_2$ penalty): hyperparameters $\alpha$ and $\ell_1$ ratio selected by
    \texttt{ElasticNetCV} with an inner cross-validation loop (9~$\alpha$ values,
    6~$\ell_1$ ratios).
  \item \textbf{Degree-2 Polynomial Regression} (polynomial feature expansion followed
    by Ridge regression via \texttt{RidgeCV}): captures pairwise interactions between
    features while remaining linear in parameters.
  \item \textbf{LightGBM} (gradient-boosted decision trees): hyperparameters (learning
    rate, number of leaves, tree depth, minimum child samples, $\ell_2$ regularisation)
    tuned by Bayesian optimisation using the Optuna TPE sampler (20~trials per inner
    fold).
\end{enumerate}

\subsection{Repeated nested cross-validation}
\label{subsec:nested_cv}

To obtain stable performance estimates that properly account for the variance introduced
by the train/validation split, model evaluation uses a repeated nested $k$-fold
cross-validation scheme.
The outer loop is repeated $R = 5$ times with independently re-seeded five-fold splits,
yielding $R \times k = 5 \times 5 = 25$~outer RMSE scores per model--sensor
combination.
For LightGBM, each outer fold contains its own inner Optuna optimisation loop, ensuring
that the reported outer scores are not contaminated by hyperparameter selection on the
outer fold data.
For the linear models, hyperparameter selection is handled by \texttt{ElasticNetCV} and
\texttt{RidgeCV} within each outer training partition.

The 25~outer scores form the empirical sampling distribution of RMSE for each model and
are used directly in the significance tests described below.

\subsection{Statistical significance testing}
\label{subsec:sig_tests}

Pairwise significance tests are conducted at two levels.

\textbf{Level 1 --- Within-sensor comparisons (architecture differences).}
For pairs of models trained on the same sensor configuration (e.g., Elastic Net vs.\
Polynomial on AE), the corrected repeated $k$-fold $t$-test of Nadeau and
Bengio~\cite{nadeau_inference_2003} is applied to the 25~paired RMSE scores.
This test corrects the standard paired $t$-test for the positive correlation induced by
shared training data across repeated folds.
The correction factor is:
\begin{equation}
  \hat{\sigma}^2_{\mathrm{corr}} = \left(\frac{1}{n_{\text{test}}} +
  \frac{n_{\text{train}}}{n_{\text{test}}}\right) \hat{\sigma}^2,
\end{equation}
where $\hat{\sigma}^2$ is the sample variance of pairwise RMSE differences and
$n_{\text{test}}/n_{\text{train}}$ is the test/train size ratio.
Multiple within-sensor comparisons are adjusted by the Holm--Bonferroni step-down
procedure at $\alpha = 0.05$.

\textbf{Level 2 --- Cross-sensor comparisons (best per sensor configuration).}
For the best model from each sensor configuration (selected by lowest mean CV RMSE),
pairwise differences on the common hold-out set are assessed by:
\begin{itemize}
  \item The Wilcoxon signed-rank test on paired residuals (non-parametric);
  \item The modified Diebold--Mariano test~\cite{harvey_testing_1997} for equal
    predictive accuracy under squared-error loss;
  \item A bootstrap $\Delta$RMSE 95\% confidence interval (10\,000 resamples with
    replacement).
\end{itemize}
Cross-sensor $p$-values are also corrected by Holm--Bonferroni.

\textbf{Overall performance.}
LightGBM achieves the best hold-out performance across all sensor configurations,
with AE-only reaching $R^2 = 0.951$, RMSE~$= 0.078$~$\kappa$-units.
On a target range of $[0.003,\, 1.64]$ with mean~0.51, this corresponds to a relative
RMSE of approximately 15\% of the target range.
Linear and polynomial models on AE features achieve $R^2 \approx 0.77$--$0.83$,
confirming a non-linear feature--$\kappa$ mapping that gradient boosting exploits
more effectively.

\textbf{Sensor comparison.}
AE features substantially outperform UL-channel features across all model families.
The LightGBM AE--UL gap ($\Delta R^2 = 0.35$) is confirmed as highly significant
(Nadeau--Bengio $p < 10^{-22}$; Wilcoxon $p < 10^{-166}$; $\Delta\text{RMSE} = 0.144$,
95\%~CI [0.133, 0.157]).
This reflects the richer frequency content and more direct physical sensitivity of
the AE sensor to asperity contact events.

\textbf{Sensor fusion yields a marginal, statistically unconfirmed improvement.}
LightGBM on the combined AE+UL feature set achieves $R^2 = 0.953$, marginally
above the AE-only result ($0.951$).
The within-CV corrected $t$-test rejects equality ($p = 0.024$), but hold-out
tests do not confirm the improvement: Wilcoxon $p = 0.88$, Diebold--Mariano $p = 0.28$,
bootstrap $\Delta\text{RMSE} = 0.0011$ with 95\%~CI $[-0.0009,\, 0.0033]$ spanning
zero.
For the linear models, the combined feature set is similarly on par with AE alone
(Elastic Net: $R^2$ 0.830 vs.\ 0.826; Polynomial: 0.803 vs.\ 0.775).
The marginal fusion gain is consistent with the UL channel contributing a small amount
of non-redundant information at low-frequency.

\textbf{Model consistency.}
The close agreement between nested CV RMSE and hold-out RMSE across all models
indicates stable generalisation with no evidence of significant overfitting.
The Bayesian Ridge reference results (hold-out only) align closely with Elastic Net,
confirming that the linear model results are not sensitive to the choice of
regularisation method.

\textbf{SHAP-based feature importance.}
SHAP (SHapley Additive exPlanations) values computed via TreeExplainer identify
which AE sub-band features drive the $\kappa$ predictions.
The dominant contributor by a large margin is \textit{1--2~MHz complexity}
(mean $|\text{SHAP}| = 0.162$), followed by \textit{500~kHz--1~MHz centre frequency}
(0.051) and \textit{1--2~MHz mobility} (0.038).
The 1--2~MHz band complexity feature is also the only feature ranked in the top~10
across all three model types (cross-model agreement, Table~\ref{tab:shap_agree}),
making it the most robust single predictor of $\kappa$ in the dataset.
Figure~\ref{fig:shap} shows the full importance ranking.
