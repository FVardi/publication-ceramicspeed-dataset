\section{Regression Modelling and Statistical Evaluation}
\label{sec:modelling}
%% ============================================================================
\subsection{Experimental design}
\label{subsec:modelling_design}
\subsubsection{Data sets and splits}
The data experiments utilise three different features sets: the AE, the US, and the combined AE and US feature sets. Each of the later described models are fitted to each of the three datasets. Each dataset is divided into a training set (80\%) and a hold-out test set (20\%) by a \emph{visit-grouped} split: sweeps are partitioned into groups corresponding to contiguous 60-second RPM holds (both sensor rows of a sweep kept together), and whole groups---rather than individual sweeps---are assigned to the training or hold-out set with \texttt{GroupShuffleSplit}. This prevents the near-duplicate windows of a single slowly-varying hold from straddling the train/test boundary, as a sweep-level random split would allow. The hold-out set is withheld entirely from all model development steps and used only for final evaluation. The training set is further divided during nested cross-validation described in Section~\ref{subsec:nested_cv}.

\subsection{Repeated nested cross-validation}
\label{subsec:nested_cv}
To obtain stable performance estimates that properly account for the variance introduced by the train/validation split, the model evaluation uses a repeated nested $k$-fold cross-validation scheme. The outer loop is repeated $R = \resNrepeats$ times with independently re-seeded, group-respecting \resNfoldsCv-fold splits (the same hold-group structure as the hold-out split, so near-duplicate windows never straddle a fold boundary), yielding $R \times k = \resNouterScores$~outer RMSE scores per model--sensor combination. See Figure~\ref{fig:data_partition} for data partitions.

\begin{figure}[H]
\centering
\includegraphics[width=1\textwidth]{figures/nested_cv_splits.png}
\caption{Data partitioning for the repeated nested cross-validation: an 80/20
group-level hold-out split (groups = 60-second RPM holds), with the training pool
further divided into $R = \resNrepeats$ independently seeded, group-respecting
\resNfoldsCv-fold outer splits and inner hyperparameter-selection folds.}
\label{fig:data_partition}
\end{figure}

For LightGBM, each outer fold contains its own inner Optuna optimisation loop, ensuring that the reported outer scores are not contaminated by hyperparameter selection on the outer fold data.
For the linear models, hyperparameter selection runs within each outer training partition: \texttt{ElasticNetCV} performs an inner 5-fold search over the $\alpha$/$\ell_1$-ratio grid, and \texttt{RidgeCV} a leave-one-out generalised cross-validation over the $\lambda$ grid; the selected hyperparameters are then refit on the full outer-training fold before the outer validation fold is scored.

The \resNouterScores~outer scores form the empirical sampling distribution of RMSE for each model and are used directly in the significance tests described below.
\subsection{Statistical significance testing}
\label{subsec:sig_tests}
Pairwise significance tests are conducted at two levels.

\textbf{Level 1 --- Within-sensor comparisons (architecture differences).}
For pairs of models trained on the same sensor configuration (e.g., Elastic Net vs.\
Polynomial on AE), the corrected repeated $k$-fold $t$-test of Nadeau and
Bengio~\cite{nadeau_inference_2003} is applied to the \resNouterScores~paired RMSE scores.
This test corrects the standard paired $t$-test for the positive correlation induced by
shared training data across repeated folds.
Multiple within-sensor comparisons are adjusted by the Holm--Bonferroni step-down
procedure at $\alpha = 0.05$.

\textbf{Level 2 --- Cross-sensor comparisons (best per sensor configuration).}
For the best model from each sensor configuration (selected by lowest mean CV RMSE),
pairwise differences on the common hold-out set are assessed by:
\begin{itemize}
  \item The Wilcoxon signed-rank test on paired residuals (non-parametric);
  \item The modified Diebold--Mariano test for equal
    predictive accuracy under squared-error loss;
  \item A bootstrap $\Delta$RMSE 95\% confidence interval (10\,000 resamples with
    replacement).
\end{itemize}
Cross-sensor $p$-values are also corrected by Holm--Bonferroni.

\textbf{Overall performance.}
LightGBM achieves the best hold-out performance across all sensor configurations,
with AE-only reaching $R^2 = \resHOrsqLgbAe$, RMSE~$= \resHOrmseLgbAe$~$\kappa$-units.
On a target range of $[\resKappaMin,\, \resKappaMax]$ with mean~\resKappaMean, this corresponds to a relative
RMSE of approximately \resRelRmsePctLgbAe\% of the mean target value.
Linear and polynomial models on AE features achieve $R^2 = \resHOrsqPolyAe$--$\resHOrsqEnetAe$,
confirming a non-linear feature--$\kappa$ mapping that gradient boosting exploits
more effectively.

\textbf{Sensor comparison.}
AE features substantially outperform US features across all model families.
The LightGBM AE--US gap ($\Delta R^2 = \resDrsqLgbAeUs$) is large and significant on the hold-out set
(Wilcoxon $p = \resPwxAeUs$; $\Delta\text{RMSE} = \resDrmseAeUs$,
95\%~CI [\resDrmseLoAeUs, \resDrmseHiAeUs]), although the corrected repeated nested-CV $t$-test does not reach significance (Nadeau--Bengio $p = \resPcvAeUs$); we report both.
This reflects the richer frequency content and more direct physical sensitivity of
the AE sensor to asperity contact events.

\textbf{Sensor fusion.}
LightGBM on the combined AE+US feature set achieves $R^2 = \resHOrsqLgbComb$
($\Delta R^2 = \resDrsqLgbCombAe$ over the AE-only result of \resHOrsqLgbAe).
The within-CV corrected $t$-test gives $p = \resPcvAeComb$; on the hold-out set,
Wilcoxon $p = \resPwxAeComb$, Diebold--Mariano $p = \resPdmAeComb$, and the bootstrap
$\Delta\text{RMSE} = \resDrmseAeComb$ with 95\%~CI $[\resDrmseLoAeComb,\, \resDrmseHiAeComb]$.
For the linear models, the combined feature set performs similarly to AE alone
(Elastic Net: $R^2$ \resHOrsqEnetComb{} vs.\ \resHOrsqEnetAe; Polynomial:
\resHOrsqPolyComb{} vs.\ \resHOrsqPolyAe).
The fusion gain is small in absolute terms but consistent across all four tests, indicating that the US channel contributes a modest amount of non-redundant information.

\textbf{Model consistency.}
The close agreement between nested CV RMSE and hold-out RMSE across all models
indicates stable generalisation with no evidence of significant overfitting.

\textbf{SHAP-based feature importance.}
SHAP (SHapley Additive exPlanations) values computed via TreeExplainer identify
which AE sub-band features drive the $\kappa$ predictions.
For LightGBM the dominant contributor by a large margin is
\textit{\resShapTopFeat} (mean $|\text{SHAP}| = \resShapTopVal$), followed by
\textit{\resShapSecondFeat} (\resShapSecondVal) and \textit{\resShapThirdFeat} (\resShapThirdVal).
The 500~kHz--1~MHz mobility feature ranks \emph{first} for both LightGBM and the
polynomial model and third for Elastic Net (behind the broadband shape factor and
20--500~kHz RMS), making it the most robust single predictor of $\kappa$ across model
families (cross-model agreement, Table~\ref{tab:shap_agree}).Figure~\ref{fig:shap} shows the full importance ranking.
