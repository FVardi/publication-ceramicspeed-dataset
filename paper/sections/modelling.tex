\subsection{Experimental design}
\label{subsec:modelling_design}
\subsubsection{Data sets and splits}
The data experiments utilise three different features sets: the AE, the US, and the combined AE and US feature sets. Each of the later described models are fitted to each of the three datasets. Each dataset is divided into a training set (80\%) and a hold-out test set (20\%) by sweep-level random sampling, stratified to preserve the $\kappa$ regime distribution. The hold-out set is withheld entirely from all model development steps and used only for final evaluation. The training set is further divided during nested cross-validation described in Section~\ref{subsec:nested_cv}.

\subsection{Repeated nested cross-validation}
\label{subsec:nested_cv}
To obtain stable performance estimates that properly account for the variance introduced by the train/validation split, the model evaluation uses a repeated nested $k$-fold cross-validation scheme. The outer loop is repeated $R = \resNrepeats$ times with independently re-seeded \resNfoldsCv-fold splits, yielding $R \times k = \resNouterScores$~outer RMSE scores per model--sensor combination. See Figure~\ref{fig:data_partition} for data partitions.

\begin{figure}[H]
\centering
\includegraphics[width=1\textwidth]{figures/nested_cv_splits.png}
\caption{Caption}

For LightGBM, each outer fold contains its own inner Optuna optimisation loop, ensuring that the reported outer scores are not contaminated by hyperparameter selection on the outer fold data.

The \resNouterScores~outer scores form the empirical sampling distribution of RMSE for each model and are used directly in the significance tests described below.
\subsection{Statistical significance testing}
\label{subsec:sig_tests}
Pairwise significance tests are conducted at two levels.

\textbf{Level 1 --- Within-sensor comparisons (architecture differences).}
For pairs of models trained on the same sensor configuration (e.g., Elastic Net vs.\
Polynomial on AE), the corrected repeated $k$-fold $t$-test of Nadeau and
Bengio~\cite{nadeau_inference_2003} is applied to the 25~paired RMSE scores.
This test corrects the standard paired $t$-test for the positive correlation induced by
shared training data across repeated folds.
Multiple within-sensor comparisons are adjusted by the Holm--Bonferroni step-down
procedure at $\alpha = 0.05$.

\textbf{Level 2 --- Cross-sensor comparisons (best per sensor configuration).}
For the best model from each sensor configuration (selected by lowest mean CV RMSE),
pairwise differences on the common hold-out set are assessed by:
\begin{itemize}
  \item The Wilcoxon signed-rank test on paired residuals (non-parametric);
  \item The modified Diebold--Mariano test for equal
    predictive accuracy under squared-error loss;
  \item A bootstrap $\Delta$RMSE 95\% confidence interval (10\,000 resamples with
    replacement).
\end{itemize}
Cross-sensor $p$-values are also corrected by Holm--Bonferroni.

\textbf{Overall performance.}
LightGBM achieves the best hold-out performance across all sensor configurations,
with AE-only reaching $R^2 = \resHOrsqLgbAe$, RMSE~$= \resHOrmseLgbAe$~$\kappa$-units.
On a target range of $[\resKappaMin,\, \resKappaMax]$ with mean~\resKappaMean, this corresponds to a relative
RMSE of approximately \resRelRmsePctLgbAe\% of the mean target value.
Linear and polynomial models on AE features achieve $R^2 = \resHOrsqPolyAe$--$\resHOrsqEnetAe$,
confirming a non-linear feature--$\kappa$ mapping that gradient boosting exploits
more effectively.

\textbf{Sensor comparison.}
AE features substantially outperform US features across all model families.
The LightGBM AE--US gap ($\Delta R^2 = \resDrsqLgbAeUs$) is confirmed as highly significant
(Nadeau--Bengio $p = \resPcvAeUs$; Wilcoxon $p = \resPwxAeUs$; $\Delta\text{RMSE} = \resDrmseAeUs$,
95\%~CI [\resDrmseLoAeUs, \resDrmseHiAeUs]).
This reflects the richer frequency content and more direct physical sensitivity of
the AE sensor to asperity contact events.

\textbf{Sensor fusion.}
LightGBM on the combined AE+US feature set achieves $R^2 = \resHOrsqLgbComb$
($\Delta R^2 = \resDrsqLgbCombAe$ over the AE-only result of \resHOrsqLgbAe).
The within-CV corrected $t$-test gives $p = \resPcvAeComb$; on the hold-out set,
Wilcoxon $p = \resPwxAeComb$, Diebold--Mariano $p = \resPdmAeComb$, and the bootstrap
$\Delta\text{RMSE} = \resDrmseAeComb$ with 95\%~CI $[\resDrmseLoAeComb,\, \resDrmseHiAeComb]$.
For the linear models, the combined feature set performs similarly to AE alone
(Elastic Net: $R^2$ \resHOrsqEnetComb{} vs.\ \resHOrsqEnetAe; Polynomial:
\resHOrsqPolyComb{} vs.\ \resHOrsqPolyAe).

\textbf{SHAP-based feature importance.} \todo{Update sections after new results}
SHAP (SHapley Additive exPlanations) values computed via TreeExplainer identify
which AE sub-band features drive the $\kappa$ predictions.
The dominant contributor by a large margin is \textit{1--2~MHz complexity}
(mean $|\text{SHAP}| = 0.162$), followed by \textit{500~kHz--1~MHz centre frequency}
(0.051) and \textit{1--2~MHz mobility} (0.038).
The 1--2~MHz band complexity feature is also the only feature ranked in the top~10
across all three model types (cross-model agreement, Table~\ref{tab:shap_agree}),
making it the most robust single predictor of $\kappa$ in the dataset.
Figure~\ref{fig:shap} shows the full importance ranking.
